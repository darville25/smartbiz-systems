FAQ

Website Design Questions Answered

How fast can you really deliver a website?
Our Startup package (5 pages) is live in 5–7 business days. Corporate (7 pages + CMS) is 7–10 days. E-Commerce takes 2–4 weeks depending on the number of products and integrations. The clock starts after you approve the mockup and provide your content.
Do I need to provide content or do you write it?
We can do both. If you have content (text, images, logo), we work with it. If not, we write all page copy, source stock imagery, and set up your brand voice — included in the Corporate and E-Commerce packages. For Startup, basic copy writing can be added for KES 8,000.
Will I be able to update the website myself?
Yes. We build on WordPress with Elementor, which is a drag-and-drop editor any non-technical person can use. We include a walkthrough video and 30–90 days of support so you're comfortable making changes. You'll never need to call us to change your phone number or add a new service.
What about hosting and domain — do I need to arrange that?
We can handle hosting setup for you if needed. We recommend Kenyan-based hosting (Truehost or Liquid Web Kenya) for speed, or international options like SiteGround. Domain registration via Kenya.com or Namecheap. We'll guide you through the whole setup and connect everything — typical annual cost is KES 8,000–15,000.
Can you redesign my existing website instead of building from scratch?
Absolutely. If you have an existing site we'll audit it first — what's ranking, what has backlinks, what to keep vs rebuild. We never throw away SEO value unnecessarily. Redesigns are quoted based on scope after the audit.
Do you integrate with social media or WhatsApp Business?
Yes — Instagram feeds, Facebook Page widgets, WhatsApp floating buttons, and click-to-chat CTAs are standard. For the full WhatsApp Business API integration (automated replies, lead capture flows), that's available as an add-on or as a separate WhatsApp Automation package.
